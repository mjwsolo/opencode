Read a file or list a directory.

- filePath is absolute. Returns up to 2000 lines as "N: content"; pass offset (1-indexed) to read further. Directory entries are one per line, subdirectories end with "/".
- Lines over 2000 characters are truncated. Use grep to find content in big files and glob to find paths.
- Read several files in one turn when you know you need them; avoid tiny repeated slices.
- Images and PDFs are returned as attachments.
